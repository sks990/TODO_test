## 목적 및 기본방침
IndexedDB 데이터 서비스 위에 Todo, Kanban, Gantt 기능에 필요한 비즈니스 로직을 구현하여 UI 컴포넌트가 데이터 저장소에 직접 의존하지 않도록 추상화하고, 애플리케이션의 핵심 상태를 일관성 있게 관리합니다.

## 실행 계획 및 방법
1.  **`TaskService` 구현**:
    *   할 일 추가(`addTask`), 조회(`getTasks`, `getTaskById`), 업데이트(`updateTask`), 삭제(`deleteTask`) 기능을 구현합니다.
    *   할 일 필터링(`status`, `priority`, `dueDateBefore`) 및 정렬(`field`, `order`) 로직을 포함합니다.
    *   `moveTaskToColumn(taskId, targetColumnId)` 기능을 구현하여 칸반 보드에서 할 일 이동을 지원합니다.
    *   `id`, `createdAt`, `updatedAt`, `isCompleted` 등 필드를 자동으로 처리합니다.
2.  **`BoardColumnService` 구현**:
    *   모든 칸반 컬럼을 조회하고(`getColumns`), 순서대로 정렬하여 반환하는 기능을 구현합니다.
    *   컬럼 순서 업데이트(`updateColumnOrder`) 기능을 구현합니다.
3.  **`SettingService` 구현**:
    *   애플리케이션 설정을 조회(`getSetting`)하고 저장/업데이트(`setSetting`)하는 기능을 구현합니다.
4.  **`StateManager` 모듈 구현**:
    *   `AppState` 객체를 정의하고, `getState()`, `setState(newState)`, `subscribe(listener)`, `notify()` 메서드를 포함하여 전역 상태 관리 로직을 구현합니다.
    *   필터링된 할 일(`filteredTasks`)과 같은 파생 상태를 관리하는 로직을 구현합니다.
5.  **Gantt 데이터 계산 로직 구현**:
    *   `calculateGanttData(tasks)` 함수를 구현하여 Gantt 차트에 필요한 기간, 위치, 종속성 데이터를 생성합니다.
    *   `startDate`와 `endDate`를 조정하는 로직(드래그 및 크기 조절 시)을 `updateTask`와 연동하여 구현합니다.
6.  **입력 유효성 검사 및 살균 (비즈니스 로직 수준)**:
    *   `addTask` 및 `updateTask` 호출 시, `title` 등의 필수 필드 유효성 검사를 수행합니다.
    *   사용자 입력 텍스트(예: `title`, `description`)를 IndexedDB에 저장하기 전에 잠재적인 XSS 공격을 방지하기 위한 살균(sanitization) 처리를 적용합니다 (예: HTML 엔티티 인코딩).

### 핵심 비즈니스 로직 및 서비스 구현

**개요:**
본 문서는 애플리케이션의 핵심 비즈니스 로직과 고수준 서비스 구현에 대한 내용을 담고 있습니다. UI 컴포넌트와 데이터 저장소(IndexedDB) 간의 의존성을 추상화하고, 애플리케이션의 상태를 일관성 있게 관리하기 위한 서비스 및 상태 관리 모듈을 구현했습니다.

**주요 구현 내용:**

*   **`TaskService`:** 할 일(Task)의 CRUD 작업, 필터링, 정렬, 칸반 보드 내 이동 기능을 제공합니다.
*   **`BoardColumnService`:** 칸반 컬럼의 조회 및 순서 변경 기능을 관리합니다.
*   **`SettingService`:** 애플리케이션 설정의 조회 및 변경 기능을 제공합니다.
*   **`StateManager`:** 애플리케이션의 전역 상태를 관리하고, 상태 변경 시 이를 구독하는 컴포넌트에 알림을 보냅니다.
*   **Gantt 데이터 계산:** Gantt 차트 렌더링에 필요한 데이터를 `Task` 객체로부터 계산하는 로직을 구현했습니다.
*   **보안:** 필수 필드 유효성 검사 및 사용자 입력 데이터에 대한 XSS 방지 살균 처리를 적용했습니다.

**사용 방법:**
UI 컴포넌트는 데이터에 직접 접근하는 대신, `TaskService`, `BoardColumnService` 등의 API를 호출하여 데이터를 조작합니다. 전역 상태 변경은 `StateManager`를 통해 이루어집니다.

**추후 고려 사항:**
Gantt 차트 기능 고도화, 오류 처리 강화, 성능 최적화 등의 작업이 필요합니다.
